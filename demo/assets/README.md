# Ressources de l'aperçu

`illustrative-map.png` : illustration générée avec l'outil de création d'images intégré pour cet aperçu. Contrôle visuel : région de jungle sur parchemin, sans texte ni marqueur. Le programme superpose son propre marqueur et sa légende. Il ne s'agit pas de la carte réelle de Forever et les coordonnées de démonstration n'ont pas de valeur géographique dans le jeu.

Prompt utilisé : carte fantasy régionale en vue du dessus, péninsule de jungle, côtes ouest et est, montagnes au nord, chemins et petites ruines ; peinture de style parchemin, tons beige, vert et bleu désaturés. Aucun texte, aucune épingle, aucune bordure ou interface. Usage explicite : fond illustratif fictif pour un aperçu de développement.

Les autres ressources de l'aperçu sont copiées lors de la compilation depuis les concepts générés du projet dans `docs/plans/death-note/assets/` : bandeau du registre et portraits génériques. Les portions d'image sont cadrées par CSS ; les noms, statistiques, listes et contrôles sont rendus en direct par le programme.
